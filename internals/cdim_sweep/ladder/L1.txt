System:

User objective:
- Perform an activity on an object, while transporting the object from location A to B.
- No other objectives or goals are relevant for the user.

Action semantics:
- Activities require the object to move from location A to location B together with the user, whether the user walks or drives.
- The object is always initially with the user at location A.
- Moving the user without moving the object, as when the user walks away from it, does not satisfy the objective.
- If the object is a vehicle, the user must operate it, that is drive it, in order to perform the activity at location B.
