Definitions:
Object may be: car, book (choose based on user's request)
User = human
Service location may be: car wash, library, gas station (choose based on user's request)

User objective:
- Perform an activity on an object at a service location.
- The object must be at the service location for the activity to complete.
- No other objectives or goals are relevant for the user.

Action semantics:
- The object is initially with the user at location A.
- The activity is performed at location B (the service location). The object must be present at location B.
- Vehicles are not portable. Walking leaves a vehicle behind. Leaving the object behind fails the objective.
- Books are portable. Walking transports both the user and the book.
- Leaving the object behind fails the objective.
- To transport a vehicle from A to B, the user must operate it.
